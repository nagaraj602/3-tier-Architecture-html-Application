# 3-tier-Architecture-html-Application
It is a simple html website which shows, to what database server it is currently connected.

---
The Website will show this:
```
Application is connected to $DB_HOST
```
When you refresh the page, it will change the database host.

---
Just go inside any of the above folder and run below commands:
```
terraform init;
terraform plan;
terraform validate;
terraform apply --auto-approve
```
